# Vizual istiqamət — Taxt və Qılınc

## Məqsəd
Realistik, detallı, canlı orta əsr qala-şəhəri. Vizual keyfiyyət hədəfi mobil strategiya oyunlarının yüksək səviyyəli 3D şəhər səhnələridir. Mövcud kommersiya oyunlarının kodu, modelləri və teksturaları kopyalanmır.

## Kamera və kompozisiya
- İzometrik / üç rüb bucaq; kamera şəhərin bütöv planını göstərə biləcək məsafədə.
- Mərkəzdə əsas qala; ətrafında müdafiə divarları, darvaza və ayrı-ayrı tikililər.
- Kışla, tövlə, oxçu meydançası, dəmirçi, anbar və bazar bir-birinin üstünə düşməyən ayrıca sahələrdə.
- Divarların xaricində yol, meşə, daşlıq və resurs nöqtələri.
- Şəhərdə vizual dərinlik: ön, orta və arxa plan.

## Materiallar və işıq
- PBR materiallar: daş, yonulmuş ağac, dam kirəmiti, metal, torpaq və bitki örtüyü.
- Realistik normal/roughness/metalness xəritələri.
- Günəş istiqamətli işıq, yumşaq kölgələr, atmosfer dumanı və ölçülü rəng korreksiyası.
- Binalarda fərqli siluetlər, dam formaları, bayraqlar, pəncərələr və müdafiə detalları.

## Keyfiyyət qaydası
- Kubik/Minecraft üslubu və çox sadə low-poly modellər final səhnəyə daxil edilmir.
- Müvəqqəti placeholder yalnız mexanika testində istifadə oluna bilər və final qrafika kimi təqdim edilə bilməz.
- Hər aktiv üçün mənbə, müəllif, lisenziya, kommersiya istifadəsi və dəyişdirmə hüququ qeydə alınmalıdır.
- Mobil optimizasiya: LOD, instancing, atlas teksturalar, məhdud dinamik kölgələr və ölçülmüş performans.

## İlk vizual səhnə
Əsas qala + daş divar və darvaza + kışla + tövlə + oxçu meydançası + anbar + yol + meşə + relyef. Bütün tikililər ayrıca oxunaqlı olmalıdır.
